# curio dig: site and game implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The playable `/dig` game on curioword.com: daily and past games, the end screen with sharing and the
daily-word signup, indexed archive pages, link previews, first-party funnel counters, and a daily health check
that emails Sam.

**Architecture:**
- The browser fetches the day file from a CDN-cached route. It decodes the answers in memory and runs the whole
  game client-side using the shared `lib/dig/match.ts`, so a guess never costs a server call.
- A pure reducer (`lib/dig/game.ts`) drives the screens. Results live in localStorage.
- One allowlisted event endpoint writes HINCRBY counters, in production only.
- Server reads use Upstash in production and preview. Locally they read the pipeline's `.dig-out/` files, or a
  built-in fake day, and never touch Redis.

**Tech stack:** Next.js 16 (App Router, read `node_modules/next/dist/docs/` first), React 19, Tailwind v4 tokens,
Vitest (node environment, `renderToStaticMarkup` for components), @upstash/redis, Resend, next/og.

**Specs:**
- `docs/rarity-game/architecture.md` (game flow §2, routes §7, keys §8, funnel §9, sharing §10, brand §11,
  security §13, MVP scope §15)
- `docs/rarity-game/mockups/option-2-dig.html`: the visual reference for every screen. Open it in the browser pane
  and match it.
- `docs/design-system.md`: read before any UI task.

**Depends on:** Plan A (`docs/superpowers/plans/2026-10-24-dig-pipeline.md`), Tasks 1–3 and 12. Those give
`lib/dig/types.ts`, `score.ts`, `normalize.ts`, `match.ts`, `payload.ts` and `keys.ts`. This plan's tasks can run
before the rest of Plan A, because local development uses the fake day.

## Global constraints

- **Local development never reads or writes production Redis.** Server reads use Redis only when `VERCEL_ENV` is
  `production` or `preview`. Writes happen only when `VERCEL_ENV === "production"`.
- **Never send email from local.** `sendDigAlert` logs a count-only line in development and throws in production
  when it isn't configured.
- **Never log secrets, addresses, answers or guesses.** Errors log `err.name` only.
- **Answers never reach the browser for a future day.** `/api/dig/today` serves only `dayKey()`;
  `/api/dig/day/[date]` serves only dates before today.
- Every Redis key comes from `lib/dig/keys.ts` (prefix `curio:dig:`).
- **Product rule, "archive, never backlog":**
  - no counts of unplayed days;
  - no "you missed";
  - no streaks;
  - no completion percentages.
  - Running out of time reads "Time's up".
- **UI:**
  - use `components/ui` (Button, TextField, ToggleGroup) only, with no hand-rolled `<button>` or `<input>`;
  - no new arbitrary Tailwind values: new tokens go in `app/globals.css`;
  - red (`--accent-button` inside `data-brand="next"`) only on Start, Share and Join;
  - tier names are always written out, never shown by colour alone;
  - respect `prefers-reduced-motion`.
- **Timer:** a 3-second read pause, then 25 seconds, with screen-reader announcements at 10 and 5 seconds. "No timer"
  removes the read pause, the clock and the announcements, and counts equally everywhere.
- **Share text, exactly:**
  ```
  curio dig, day N
  X.X m down
  <emoji row>
  curioword.com/dig
  ```
- **Copy:**
  - sentence case;
  - lowercase "curio dig" as the game's name;
  - no "→" on buttons;
  - no middle-dot meta strings.
- **Commands:** `npx vitest run <path>`, `npm run lint`, `npx tsc --noEmit`, and the preview server via `preview_start`.

## Changes to the specs made by this plan

1. **The day file carries no `number`.** `/api/dig/today` adds it from `DIG_LAUNCH_DATE`, so the launch date can
   be chosen after days are built. Fossils and story links sit inside the obfuscated payload, not beside it, because
   a fossil is a spoiler.
2. **Past-day responses use `s-maxage=86400, stale-while-revalidate=604800`, not `immutable`.** Weekly adjudication
   can add accepted-only answers to past days.
3. **Signup is counted by the browser.** It sends a `signup` event after `/api/subscribe` succeeds, and
   `/api/subscribe` is left unchanged.
4. **The percentile line appears only from 50 finishers.** Below that, no line is shown rather than "deeper than
   most", which would be untrue for low scores.
5. **The share card is one square 1080×1080 image.** It works in chat apps and on Instagram, so there's no second
   1200×630 size.
6. **The edge-request alert uses an estimate.** Vercel publishes no usage API for Hobby, so the health cron estimates
   edge requests from first-party counters:
   - 8 per dig landing;
   - 6 per site visit (architecture §12).
   - It alerts at 50% and 70% with a projected date. Vercel's own usage emails are the authoritative backstop.
   - Recalibrate both constants against the Vercel dashboard after launch week 1.
7. **Past days are played at `/dig/<date>/play`.** That page is `noindex`. The archive page `/dig/<date>` stays the
   indexed, spoiler-full page.

```ts
import { DAY_MS, dayKey, dayStart } from "../day";

/** The dig game's calendar, on Curio's one clock (lib/day.ts, 00:00 UTC). Server-side:
 * DIG_LAUNCH_DATE is not a NEXT_PUBLIC variable, so browsers get the day number from
 * /api/dig/today instead of calling this. */

const DATE_RE = /^\d{4}-\d{2}-\d{2}$/;

/** Local and preview builds open the game from this date so it can be played before launch. */
export const DEV_LAUNCH_DATE = "2026-10-01";

export function isDateKey(s: string): boolean {
  return DATE_RE.test(s) && !Number.isNaN(dayStart(s).getTime()) && dayKey(dayStart(s)) === s;
}

/** Production stays closed (404) until Sam sets DIG_LAUNCH_DATE, so merging the code
 * can't launch the game before the pipeline has filled its buffer. */
export function digLaunchDate(env: NodeJS.ProcessEnv = process.env): string | null {
  const v = env.DIG_LAUNCH_DATE;
  if (v && isDateKey(v)) return v;
  return env.VERCEL_ENV === "production" ? null : DEV_LAUNCH_DATE;
}

export function isDigOpen(now: Date = new Date(), launch: string | null = digLaunchDate()): boolean {
  return !!launch && dayKey(now) >= launch;
}

export function dayNumber(date: string, launch: string): number {
  return Math.round((dayStart(date).getTime() - dayStart(launch).getTime()) / DAY_MS) + 1;
}

export function secondsToRollover(now: Date = new Date()): number {
  const next = dayStart(dayKey(now)).getTime() + DAY_MS;
  return Math.max(1, Math.ceil((next - now.getTime()) / 1000));
}

export function isPastDay(date: string, now: Date = new Date(), launch: string | null = digLaunchDate()): boolean {
  return isDateKey(date) && !!launch && date >= launch && date < dayKey(now);
}
```

```ts
import { isTrafficSource, type TrafficSource } from "../traffic";
import { digKeys } from "./keys";
import { isValidScore } from "./score";
import { TIERS, type Tier } from "./types";

/** The only gate between a public request body and a Redis field name (architecture §8–9),
 * modelled on lib/traffic.ts's parseTrafficEvent. Today-only events must name today. */
export type DigEvent =
  | { kind: "land"; source: TrafficSource }
  | { kind: "start"; date: string }
  | { kind: "past" }
  | { kind: "share"; how: "text" | "image" }
  | { kind: "story" }
  | { kind: "signup" }
  | { kind: "finish"; date: string; score: number; tiers: (Tier | null)[]; rejected: [number, string][] }
  | { kind: "claim"; date: string; prompt: number; guess: string };

/** Letters (any script), apostrophes, spaces and hyphens: a word someone typed, nothing else. */
export const GUESS_RE = /^[\p{L}' -]{2,40}$/u;
export const MAX_REJECTED_PER_FINISH = 21;
const PROMPTS = 7;

const isPromptIndex = (n: unknown): n is number => Number.isInteger(n) && (n as number) >= 0 && (n as number) < PROMPTS;
const cleanGuess = (g: unknown): string | null => {
  if (typeof g !== "string") return null;
  const s = g.trim().toLowerCase();
  return GUESS_RE.test(s) ? s : null;
};

export function parseDigEvent(body: unknown, today: string): DigEvent | null {
  if (typeof body !== "object" || body === null) return null;
  const b = body as Record<string, unknown>;
  switch (b.kind) {
    case "land":
      return isTrafficSource(b.source) ? { kind: "land", source: b.source } : null;
    case "start":
      return b.date === today ? { kind: "start", date: today } : null;
    case "past":
    case "story":
    case "signup":
      return { kind: b.kind };
    case "share":
      return b.how === "text" || b.how === "image" ? { kind: "share", how: b.how } : null;
    case "claim": {
      const guess = cleanGuess(b.guess);
      return b.date === today && isPromptIndex(b.prompt) && guess ? { kind: "claim", date: today, prompt: b.prompt, guess } : null;
    }
    case "finish": {
      if (b.date !== today || !isValidScore(b.score)) return null;
      if (!Array.isArray(b.tiers) || b.tiers.length !== PROMPTS) return null;
      if (!b.tiers.every((t) => t === null || (TIERS as readonly unknown[]).includes(t))) return null;
      if (!Array.isArray(b.rejected) || b.rejected.length > MAX_REJECTED_PER_FINISH) return null;
      const rejected: [number, string][] = [];
      for (const r of b.rejected) {
        if (!Array.isArray(r) || !isPromptIndex(r[0])) return null;
        const g = cleanGuess(r[1]);
        if (!g) return null;
        rejected.push([r[0], g]);
      }
      return { kind: "finish", date: today, score: b.score, tiers: b.tiers as (Tier | null)[], rejected };
    }
    default:
      return null;
  }
}

/** The funnel hash field an event increments; null for events with their own keys. */
export function funnelField(ev: DigEvent): string | null {
  switch (ev.kind) {
    case "land": return `land:${ev.source}`;
    case "start": return "start";
    case "past": return "past:start";
    case "share": return `share:${ev.how}`;
    case "story": return "story";
    case "signup": return "signup";
    case "finish": return "finish";
    case "claim": return null;
  }
}

export type Incr = [key: string, field: string, by: number];

/** Every write a finish makes, merged so a repeated guess is one HINCRBY. */
export function planFinish(ev: Extract<DigEvent, { kind: "finish" }>): Incr[] {
  const out: Incr[] = [
    [digKeys.scores(ev.date), String(Math.floor(ev.score / 10)), 1],
    [digKeys.funnel(ev.date), "finish", 1],
  ];
  const rej = new Map<string, Incr>();
  for (const [i, g] of ev.rejected) {
    const key = `${i}|${g}`;
    const hit = rej.get(key);
    if (hit) hit[2]++;
    else rej.set(key, [digKeys.rejected(ev.date, i), g, 1]);
  }
  return [...out, ...rej.values()];
}
```

```ts
import { existsSync, readFileSync, readdirSync } from "node:fs";
import path from "node:path";
import { Redis } from "@upstash/redis";
import { redis as siteRedis } from "../redis";
import { DAY_MS, dayKey, dayStart } from "../day";
import { digLaunchDate, isPastDay } from "./clock";
import { devDay } from "./devDay";
import { funnelField, planFinish, type DigEvent } from "./events";
import { digKeys, type DigManifest } from "./keys";
import { encodeDay } from "./payload";
import type { DigDay } from "./types";

/** Server-only. Reads use Upstash in production and preview; writes only in production
 * (local dev can share production's Upstash, and must never read or write it). Locally,
 * days come from the pipeline's .dig-out/ files, else lib/dig/devDay.ts. */

export const readsRedis = () => process.env.VERCEL_ENV === "production" || process.env.VERCEL_ENV === "preview";
export const writesRedis = () => process.env.VERCEL_ENV === "production";

/** DIG_REDIS_REST_URL/TOKEN move the game onto its own database later (architecture §12)
 * without a code change; otherwise the site's shared client. */
let client: Redis | null | undefined;
function digRedis(): Redis | null {
  if (client !== undefined) return client;
  const url = process.env.DIG_REDIS_REST_URL, token = process.env.DIG_REDIS_REST_TOKEN;
  client = url && token ? new Redis({ url, token }) : siteRedis;
  return client;
}

const localDir = () => path.resolve(process.cwd(), process.env.DIG_LOCAL_DIR ?? ".dig-out");
const toCounts = (h: Record<string, unknown> | null | undefined) =>
  Object.fromEntries(Object.entries(h ?? {}).map(([k, v]) => [k, Number(v) || 0]));

export async function readDay(date: string): Promise<DigDay | null> {
  if (readsRedis()) return (await digRedis()?.get<DigDay>(digKeys.day(date))) ?? null;
  const file = path.join(localDir(), "days", `${date}.json`);
  if (existsSync(file)) return JSON.parse(readFileSync(file, "utf8")) as DigDay;
  return encodeDay(devDay(date));
}

export async function readManifest(): Promise<DigManifest | null> {
  if (!readsRedis()) return null;
  return (await digRedis()?.get<DigManifest>(digKeys.manifest)) ?? null;
}

async function builtDates(now: Date): Promise<string[]> {
  if (readsRedis()) return Object.keys((await readManifest())?.days ?? {});
  const days = path.join(localDir(), "days");
  if (existsSync(days)) return readdirSync(days).filter((f) => f.endsWith(".json")).map((f) => f.slice(0, 10));
  const out: string[] = [];
  for (let t = dayStart(dayKey(now)).getTime() - DAY_MS, i = 0; i < 60; i++, t -= DAY_MS) out.push(dayKey(new Date(t)));
  return out;
}

/** Launched days before today, newest first. */
export async function pastDates(now: Date = new Date()): Promise<string[]> {
  const launch = digLaunchDate();
  return (await builtDates(now)).filter((d) => isPastDay(d, now, launch)).sort().reverse();
}

export async function recordFunnel(date: string, ev: DigEvent): Promise<void> {
  const field = funnelField(ev);
  const r = digRedis();
  if (!field || !r || !writesRedis()) return;
  await r.hincrby(digKeys.funnel(date), field, 1);
}

/** One pipelined round trip: the score bucket, the funnel, rejected guesses, and the
 * day's spread read back for the end screen's percentile. */
export async function recordFinish(ev: Extract<DigEvent, { kind: "finish" }>): Promise<Record<string, number>> {
  const r = digRedis();
  if (!r || !writesRedis()) return {};
  const p = r.pipeline();
  for (const [key, field, by] of planFinish(ev)) p.hincrby(key, field, by);
  p.hgetall(digKeys.scores(ev.date));
  const results = await p.exec();
  return toCounts(results.at(-1) as Record<string, unknown> | null);
}

export async function recordClaim(ev: Extract<DigEvent, { kind: "claim" }>): Promise<void> {
  const r = digRedis();
  if (!r || !writesRedis()) return;
  await r.hincrby(digKeys.claims(ev.date, ev.prompt), ev.guess, 1);
}

/** Everything the health cron reads, in one pipelined round trip. */
export async function healthReads(today: string, tomorrow: string, month: string) {
  const r = digRedis();
  if (!r) return null;
  const p = r.pipeline();
  p.get(digKeys.manifest);
  p.exists(digKeys.day(today));
  p.exists(digKeys.day(tomorrow));
  p.get(digKeys.usageAlert(month));
  const [manifest, todayExists, tomorrowExists, usageSent] = await p.exec();
  return {
    manifest: (manifest as DigManifest | null) ?? null,
    todayExists: Number(todayExists) === 1,
    tomorrowExists: Number(tomorrowExists) === 1,
    usageSent: Number(usageSent) || 0,
  };
}

const COUNTER_TTL = 35 * 24 * 60 * 60, FUNNEL_TTL = 90 * 24 * 60 * 60;

/** HINCRBY sets no expiry, and adding EXPIRE to every event would double the writes, so
 * the daily cron sets yesterday's (architecture §8): 16 commands a day. */
export async function housekeep(yesterday: string): Promise<void> {
  const r = digRedis();
  if (!r || !writesRedis()) return;
  const p = r.pipeline();
  p.expire(digKeys.scores(yesterday), COUNTER_TTL);
  p.expire(digKeys.funnel(yesterday), FUNNEL_TTL);
  for (let i = 0; i < 7; i++) {
    p.expire(digKeys.rejected(yesterday, i), COUNTER_TTL);
    p.expire(digKeys.claims(yesterday, i), COUNTER_TTL);
  }
  await p.exec();
}

export async function writeHeartbeat(at: Date): Promise<void> {
  const r = digRedis();
  if (r && writesRedis()) await r.set(digKeys.heartbeat, at.toISOString());
}

export async function markUsageAlert(month: string, level: number): Promise<void> {
  const r = digRedis();
  if (r && writesRedis()) await r.set(digKeys.usageAlert(month), level, { ex: 40 * 24 * 60 * 60 });
}

export async function funnelDays(dates: string[]): Promise<Record<string, Record<string, number>>> {
  const r = digRedis();
  if (!r || !readsRedis() || !dates.length) return {};
  const p = r.pipeline();
  for (const d of dates) p.hgetall(digKeys.funnel(d));
  const results = await p.exec();
  const out: Record<string, Record<string, number>> = {};
  dates.forEach((d, i) => {
    const h = toCounts(results[i] as Record<string, unknown> | null);
    if (Object.keys(h).length) out[d] = h;
  });
  return out;
}
```

```ts
const NO_STORE = { "Cache-Control": "no-store" };

/** Today's day file only: browsers never compute "today", so a wrong device clock can't

  if (!day) return NextResponse.json({ error: "Today's dig isn't ready." }, { status: 503, headers: NO_STORE });

    { ...day, number: dayNumber(date, launch) },
    { headers: { "Cache-Control": `public, max-age=0, s-maxage=${secondsToRollover(now)}` } }
  );
```

```ts
import { NextRequest, NextResponse } from "next/server";
import { dayKey } from "@/lib/day";
import { isLikelyBot } from "@/lib/traffic";
import { parseDigEvent } from "@/lib/dig/events";
import { recordClaim, recordFinish, recordFunnel } from "@/lib/dig/server";

/** The dig game's one write endpoint (architecture §8), with /api/traffic's safeguards:
 * JSON only, same-origin only, bots get a silent 204, nothing identifies the sender, and a
 * recording failure never surfaces to the page. Writes happen in production only (server.ts). */
export async function POST(req: NextRequest) {
  if (!req.headers.get("content-type")?.startsWith("application/json")) {
    return NextResponse.json({ error: "Unsupported content type." }, { status: 415 });
  }
  const site = req.headers.get("sec-fetch-site");
  if (site && site !== "same-origin") return NextResponse.json({ error: "Forbidden." }, { status: 403 });
  let body: unknown;
  try {
    body = await req.json();
  } catch {
    return NextResponse.json({ error: "Invalid request body." }, { status: 400 });
  }
  const today = dayKey();
  const ev = parseDigEvent(body, today);
  if (!ev) return NextResponse.json({ error: "Unknown event." }, { status: 400 });
  if (isLikelyBot(req.headers.get("user-agent"))) return new NextResponse(null, { status: 204 });
  try {
    if (ev.kind === "finish") return NextResponse.json({ spread: await recordFinish(ev) });
    if (ev.kind === "claim") await recordClaim(ev);
    else await recordFunnel(today, ev);
  } catch (err) {
    console.error("dig: event failed", err instanceof Error ? err.name : "unknown");
  }
  return new NextResponse(null, { status: 204 });
}
```

```ts
import { buildLookup, checkGuess, type Lookup } from "./match";
import { normalizeKey } from "./normalize";
import { decodeSecret } from "./payload";
import type { DigDay, PromptKind, PromptSecret, Tier } from "./types";

/** The whole game as a pure reducer (architecture §2): screens render from GameState,
 * a 1-second interval dispatches "tick", and nothing here touches the DOM or storage. */

export type DigDayResponse = DigDay & { number: number };
export type PreparedDay = {
  date: string;
  number: number;
  rejSample: number;
  prompts: { id: string; kind: PromptKind; text: string }[];
  secrets: PromptSecret[];
  lookups: Lookup[];
};

export function prepareDay(d: DigDayResponse): PreparedDay {
  const secrets = d.prompts.map((p) => decodeSecret(p.payload, d.date, p.id));
  return {
    date: d.date,
    number: d.number,
    rejSample: d.rejSample,
    prompts: d.prompts.map(({ id, kind, text }) => ({ id, kind, text })),
    secrets,
    lookups: secrets.map(buildLookup),
  };
}

export const READ_SECONDS = 3;
export const ANSWER_SECONDS = 25;
export const MAX_REJECTED = 3;

export type PromptResult = { answer: string | null; tier: Tier | null; rejected: string[] };
export type Feedback =
  | { kind: "near"; guess: string; suggestion: string; index: number }
  | { kind: "miss"; guess: string }
  | { kind: "empty" }
  | null;
export type GameState = {
  phase: "intro" | "reading" | "answering" | "reveal" | "done";
  current: number;
  noTimer: boolean;
  /** seconds left in the read pause or the answer window; 0 with No timer */
  clock: number;
  feedback: Feedback;
  results: PromptResult[];
};
export type GameAction = { type: "start"; noTimer: boolean } | { type: "tick" } | { type: "submit"; guess: string } | { type: "next" };

export function initialGame(): GameState {
  return { phase: "intro", current: 0, noTimer: false, clock: 0, feedback: null, results: [] };
}

function enterPrompt(s: GameState, current: number): GameState {
  return { ...s, current, feedback: null, phase: s.noTimer ? "answering" : "reading", clock: s.noTimer ? 0 : READ_SECONDS };
}

export function createReducer(day: Pick<PreparedDay, "secrets" | "lookups">) {
  const lock = (s: GameState, index: number | null): GameState => {
    const a = index === null ? null : day.secrets[s.current].answers[index];
    const results = [...s.results];
    results[s.current] = { ...results[s.current], answer: a ? a[0] : null, tier: a ? a[1] : null };
    return { ...s, results, phase: "reveal", feedback: null, clock: 0 };
  };
  return function reduce(s: GameState, a: GameAction): GameState {
    switch (a.type) {
      case "start":
        if (s.phase !== "intro") return s;
        return enterPrompt({ ...s, noTimer: a.noTimer, results: day.secrets.map(() => ({ answer: null, tier: null, rejected: [] })) }, 0);
      case "tick":
        if (s.noTimer) return s;
        if (s.phase === "reading") return s.clock > 1 ? { ...s, clock: s.clock - 1 } : { ...s, phase: "answering", clock: ANSWER_SECONDS };
        if (s.phase === "answering") return s.clock > 1 ? { ...s, clock: s.clock - 1 } : lock(s, null);
        return s;
      case "submit": {
        if (s.phase !== "answering") return s;
        if (s.feedback?.kind === "near" && normalizeKey(a.guess) === normalizeKey(s.feedback.guess)) return lock(s, s.feedback.index);
        const r = checkGuess(day.lookups[s.current], a.guess);
        if (r.kind === "match") return lock(s, r.index);
        if (r.kind === "empty") return { ...s, feedback: { kind: "empty" } };
        if (r.kind === "near") {
          return { ...s, feedback: { kind: "near", guess: a.guess, suggestion: day.secrets[s.current].answers[r.index][0], index: r.index } };
        }
        const prev = s.results[s.current];
        const g = a.guess.trim().toLowerCase();
        const rejected = prev.rejected.includes(g) || prev.rejected.length >= MAX_REJECTED ? prev.rejected : [...prev.rejected, g];
        const results = [...s.results];
        results[s.current] = { ...prev, rejected };
        return { ...s, results, feedback: { kind: "miss", guess: a.guess } };
      }
      case "next":
        if (s.phase !== "reveal") return s;
        return s.current + 1 >= day.secrets.length ? { ...s, phase: "done" } : enterPrompt(s, s.current + 1);
    }
  };
}

export const resultTiers = (s: GameState): (Tier | null)[] => s.results.map((r) => r.tier);
```

```ts
"use client";

import { useSyncExternalStore } from "react";
import type { Tier } from "./types";

/** localStorage key curio:dig, version 1 (architecture §7). No account sync in the MVP. */
const KEY = "curio:dig";
const MAX_GAMES = 400;

export type StoredGame = {
  answers: (string | null)[];
  tiers: (Tier | null)[];
  score: number;
  finishedAt: string;
  /** today's score spread, saved so a reload doesn't ask again */
  spread?: Record<string, number>;
  /** the finish event has been sent (one per browser per day) */
  reported?: boolean;
};
export type DigStore = { v: 1; settings: { noTimer: boolean }; games: Record<string, StoredGame> };

const empty = (): DigStore => ({ v: 1, settings: { noTimer: false }, games: {} });

export function parseStore(raw: string | null): DigStore {
  if (!raw) return empty();
  try {
    const s = JSON.parse(raw) as Partial<DigStore>;
    if (s?.v !== 1 || typeof s.games !== "object" || !s.games) return empty();
    return { v: 1, settings: { noTimer: !!s.settings?.noTimer }, games: s.games };
  } catch {
    return empty();
  }
}

export function withGame(store: DigStore, date: string, game: StoredGame): DigStore {
  const games = { ...store.games, [date]: game };
  const dates = Object.keys(games).sort();
  for (const d of dates.slice(0, Math.max(0, dates.length - MAX_GAMES))) delete games[d];
  return { ...store, games };
}

const listeners = new Set<() => void>();
let cache: { raw: string | null; value: DigStore } | null = null;
const SERVER_STORE = empty();

function readStore(): DigStore {
  if (typeof window === "undefined") return SERVER_STORE;
  let raw: string | null = null;
  try { raw = window.localStorage.getItem(KEY); } catch { /* private mode */ }
  if (cache && cache.raw === raw) return cache.value;
  cache = { raw, value: parseStore(raw) };
  return cache.value;
}

function writeStore(store: DigStore) {
  try { window.localStorage.setItem(KEY, JSON.stringify(store)); } catch { /* full or private: play still works */ }
  cache = null;
  listeners.forEach((l) => l());
}

export function useDigStore(): DigStore {
  return useSyncExternalStore(
    (l) => { listeners.add(l); return () => listeners.delete(l); },
    readStore,
    () => SERVER_STORE
  );
}

export function saveGame(date: string, game: StoredGame) { writeStore(withGame(readStore(), date, game)); }
export function setNoTimer(on: boolean) { const s = readStore(); writeStore({ ...s, settings: { noTimer: on } }); }
export function markReported(date: string, spread: Record<string, number> | null) {
  const s = readStore();
  const g = s.games[date];
  if (g) writeStore(withGame(s, date, { ...g, reported: true, ...(spread ? { spread } : {}) }));
}
```

```ts
import { formatDepth, shareRow } from "./score";
import type { Tier } from "./types";

/** The agreed spoiler-free share text (architecture §10). */
export function shareText(n: number, score: number, tiers: (Tier | null)[]): string {
  return [`curio dig, day ${n}`, `${formatDepth(score)} down`, shareRow(tiers), "curioword.com/dig"].join("\n");
}

const MIN_FINISHERS = 50;

/** "Deeper than 72% of today's diggers": the share of finishers in a lower score bucket.
 * Nothing below 50 finishers, and nothing when nobody is shallower: never a ranking. */
export function percentileLine(spread: Record<string, number> | undefined, score: number): string | null {
  if (!spread) return null;
  const total = Object.values(spread).reduce((a, b) => a + b, 0);
  if (total < MIN_FINISHERS) return null;
  const mine = Math.floor(score / 10);
  const below = Object.entries(spread).reduce((a, [b, n]) => (Number(b) < mine ? a + n : a), 0);
  const pct = Math.floor((below / total) * 100);
  return pct >= 1 ? `Deeper than ${pct}% of today's diggers` : null;
}
```

```ts
 * tones from paper to ink, never red (red is for actions only). */

export function strataLayout(tiers: (Tier | null)[], width: number, height: number) {
  const h = height / STRATA.length;
  return {
    bands: STRATA.map((name, i) => ({ name, y: i * h, h })),
    markers: tiers.map((t, i) => {
      const band = bandOf(t);
      return { x: (width * (i + 0.5)) / tiers.length, y: band === null ? 0 : h * (band + 0.5), band };
    }),
  };
```

```ts
"use client";

import { getArrivalSource } from "../trafficClient";

/** Browser side of /api/dig/event: fire-and-forget like lib/trafficClient.ts. Analytics
 * never throws into the game. */
export function sendDigEvent(ev: object): void {
  try {
    void fetch("/api/dig/event", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(ev), keepalive: true }).catch(() => {});
  } catch {
    // best-effort only
  }
}

/** The finish event, which returns today's score spread for the percentile line. */
export async function sendFinish(ev: object): Promise<Record<string, number> | null> {
  try {
    const res = await fetch("/api/dig/event", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify(ev) });
    if (res.status !== 200) return null;
    const body = (await res.json()) as { spread?: Record<string, number> };
    return body.spread ?? null;
  } catch {
    return null;
  }
}

const LANDED = "curio:dig:landed"; // sessionStorage: one land per tab session

/** Counts the first /dig view of a tab session, credited to the session's arrival source. */
export function sendLandOnce(): void {
  try {
    if (window.sessionStorage.getItem(LANDED)) return;
    window.sessionStorage.setItem(LANDED, "1");
    sendDigEvent({ kind: "land", source: getArrivalSource() });
  } catch {
    // private mode: better to under-count
  }
}
```

```tsx
"use client";

import { useEffect, useMemo, useReducer, useRef, useState } from "react";
import { createReducer, initialGame, prepareDay, resultTiers, type DigDayResponse, type PreparedDay } from "@/lib/dig/game";
import { scoreOf, formatDepth } from "@/lib/dig/score";
import { markReported, saveGame, setNoTimer, useDigStore } from "@/lib/dig/storage";
import { sendDigEvent, sendFinish, sendLandOnce } from "@/lib/dig/client";
import Intro from "./Intro";
import PromptScreen from "./PromptScreen";
import Reveal from "./Reveal";

/** Loads a day (today, or a past date) and plays it. Today's game reports start/finish;
 * a past game records locally only and reports a single past:start. */
export default function DigGame({ date }: { date?: string }) {
  const [day, setDay] = useState<PreparedDay | null>(null);
  const [failed, setFailed] = useState(false);
  useEffect(() => {
    let alive = true;
    fetch(date ? `/api/dig/day/${date}` : "/api/dig/today")
      .then((r) => (r.ok ? (r.json() as Promise<DigDayResponse>) : Promise.reject(new Error(String(r.status)))))
      .then((d) => alive && setDay(prepareDay(d)))
      .catch(() => alive && setFailed(true));
    if (!date) sendLandOnce();
    return () => { alive = false; };
  }, [date]);
  if (failed) return <p className="mt-8 font-sans text-ink-soft">Today&apos;s dig didn&apos;t load. Refresh to try again.</p>;
  if (!day) return <p className="mt-8 font-sans text-ink-faint" aria-live="polite">Loading the dig…</p>;
  return <DigRun day={day} isToday={!date} />;
}

function DigRun({ day, isToday }: { day: PreparedDay; isToday: boolean }) {
  const store = useDigStore();
  const reduce = useMemo(() => createReducer(day), [day]);
  const [state, dispatch] = useReducer(reduce, undefined, initialGame);
  const [claimed, setClaimed] = useState<Set<number>>(new Set());
  const saved = useRef(false);
  const finished = store.games[day.date];

  const ticking = !state.noTimer && (state.phase === "reading" || state.phase === "answering");
  useEffect(() => {
    if (!ticking) return;
    const id = window.setInterval(() => dispatch({ type: "tick" }), 1000);
    return () => window.clearInterval(id);
  }, [ticking, state.current]);

  useEffect(() => {
    if (state.phase !== "done" || saved.current) return;
    saved.current = true;
    const tiers = resultTiers(state);
    const score = scoreOf(tiers);
    saveGame(day.date, { answers: state.results.map((r) => r.answer), tiers, score, finishedAt: new Date().toISOString() });
    if (!isToday || store.games[day.date]?.reported) return;
    const report = Math.random() < day.rejSample;
    const rejected = report ? state.results.flatMap((r, i) => r.rejected.map((g) => [i, g] as [number, string])) : [];
    void sendFinish({ kind: "finish", date: day.date, score, tiers, rejected }).then((spread) => markReported(day.date, spread));
  }, [state, day, isToday, store.games]);

  if (finished && state.phase === "intro") {
    // Already played: show their own result, never a countdown.
    return <p className="mt-8 font-display text-4xl">{`${formatDepth(finished.score)} down`}</p>;
  }
  if (state.phase === "intro") {
    return (
      <Intro
        noTimer={store.settings.noTimer}
        onToggleTimer={() => setNoTimer(!store.settings.noTimer)}
        onStart={() => {
          sendDigEvent(isToday ? { kind: "start", date: day.date } : { kind: "past" });
          dispatch({ type: "start", noTimer: store.settings.noTimer });
        }}
      />
    );
  }
  if (state.phase === "done") {
    return <p className="mt-8 font-display text-4xl">{`${formatDepth(scoreOf(resultTiers(state)))} down`}</p>;
  }
  if (state.phase === "reveal") {
    return (
      <Reveal
        result={state.results[state.current]}
        secret={day.secrets[state.current]}
        isLast={state.current === day.prompts.length - 1}
        claimed={claimed.has(state.current)}
        onNext={() => dispatch({ type: "next" })}
        onClaim={(guess) => {
          if (isToday) sendDigEvent({ kind: "claim", date: day.date, prompt: state.current, guess });
          setClaimed(new Set(claimed).add(state.current));
        }}
      />
    );
  }
  return (
    <PromptScreen
      key={state.current}
      index={state.current}
      total={day.prompts.length}
      prompt={day.prompts[state.current]}
      phase={state.phase}
      clock={state.clock}
      noTimer={state.noTimer}
      feedback={state.feedback}
      onSubmit={(guess) => dispatch({ type: "submit", guess })}
    />
  );
}
```

```ts
"use client";

import { formatDepth } from "@/lib/dig/score";
import { STRATA, STRATUM_DARK, STRATUM_HEX, strataLayout } from "@/lib/dig/strata";
import type { Tier } from "@/lib/dig/types";

const SIZE = 1080;
const INK = "#1C1A17", PAPER = "#F5F1E8";

/** The player's share card, drawn in the browser (architecture §10): zero server time.
 * Spoiler-free, like the share text: depths only, no words. */
export async function shareImage(input: { number: number; score: number; tiers: (Tier | null)[]; text: string }): Promise<"shared" | "downloaded" | "failed"> {
  try {
    await document.fonts.load('700 72px "Libre Caslon Text"');
    const canvas = document.createElement("canvas");
    canvas.width = SIZE;
    canvas.height = SIZE;
    const ctx = canvas.getContext("2d");
    if (!ctx) return "failed";
    ctx.fillStyle = PAPER;
    ctx.fillRect(0, 0, SIZE, SIZE);
    ctx.fillStyle = INK;
    ctx.font = '700 64px "Libre Caslon Text", Georgia, serif';
    ctx.fillText("curio dig", 80, 140);
    ctx.font = '400 40px "Work Sans", system-ui, sans-serif';
    ctx.fillText(`day ${input.number}`, 80, 200);
    ctx.font = '700 96px "Libre Caslon Text", Georgia, serif';
    ctx.fillText(`${formatDepth(input.score)} down`, 80, 330);
    const top = 400, h = 600, w = SIZE - 160;
    const { bands, markers } = strataLayout(input.tiers, w, h);
    bands.forEach((b, i) => {
      ctx.fillStyle = STRATUM_HEX[i];
      ctx.fillRect(80, top + b.y, w, b.h);
      ctx.fillStyle = STRATUM_DARK[i] ? PAPER : INK;
      ctx.font = '400 26px "Work Sans", system-ui, sans-serif';
      ctx.fillText(STRATA[i], 96, top + b.y + 36);
    });
    markers.forEach((m, i) => {
      ctx.fillStyle = m.band !== null && STRATUM_DARK[m.band] ? PAPER : INK;
      ctx.beginPath();
      ctx.arc(80 + m.x, top + Math.max(m.y, 14), input.tiers[i] === "fossil" ? 26 : 16, 0, Math.PI * 2);
      ctx.fill();
    });
    const blob = await new Promise<Blob | null>((resolve) => canvas.toBlob(resolve, "image/png"));
    if (!blob) return "failed";
    const file = new File([blob], `curio-dig-day-${input.number}.png`, { type: "image/png" });
    if (navigator.canShare?.({ files: [file] })) {
      await navigator.share({ files: [file], text: input.text });
      return "shared";
    }
    const url = URL.createObjectURL(blob);
    const a = document.createElement("a");
    a.href = url;
    a.download = file.name;
    a.click();
    setTimeout(() => URL.revokeObjectURL(url), 10_000);
    return "downloaded";
  } catch {
    return "failed";
  }
}
```

```ts
import { DAY_MS, dayStart } from "../day";
import type { DigManifest } from "./keys";

/** pipeline-design §13 watchdog 2: problems in plain words, counts only (they go into an
 * email). An empty list means healthy. */
export function evaluateHealth(i: { today: string; manifest: DigManifest | null; todayExists: boolean; tomorrowExists: boolean; launch: string | null; now: Date }): string[] {
  if (!i.manifest) return i.launch ? ["The dig pipeline has never published, but DIG_LAUNCH_DATE is set."] : [];
  const problems: string[] = [];
  if (i.launch && i.today >= i.launch && !i.todayExists) problems.push("Today's dig is missing, so /dig shows an error.");
  if (!i.tomorrowExists) problems.push("Tomorrow's dig is missing.");
  const furthest = Object.keys(i.manifest.days).sort().at(-1);
  const buffer = furthest ? Math.round((dayStart(furthest).getTime() - dayStart(i.today).getTime()) / DAY_MS) : 0;
  if (buffer < 14) problems.push(`Only ${Math.max(buffer, 0)} days are built ahead (alert below 14).`);
  const age = Math.floor((i.now.getTime() - Date.parse(i.manifest.lastRun)) / DAY_MS);
  if (age > 9) problems.push(`The pipeline last published ${age} days ago (alert after 9).`);
  return problems;
}

/** Vercel publishes no usage API for Hobby, so this is an estimate from first-party
 * counters (architecture §12's per-visit figures). Recalibrate against the Vercel
 * dashboard after launch week 1. Vercel's own usage emails are the backstop. */
export const EDGE_PER_DIG_LAND = 8;
export const EDGE_PER_SITE_VISIT = 6;
export const HOBBY_EDGE_REQUESTS = 1_000_000;

export function estimateEdgeRequests(digLands: number, siteVisits: number): number {
  return digLands * EDGE_PER_DIG_LAND + siteVisits * EDGE_PER_SITE_VISIT;
}

/** One alert at 50% and one at 70% of the month's allotment (decided 2026-10-24), with
 * the date the current daily rate reaches 100%. The upgrade is Sam's call. */
export function usageAlert(i: { estimated: number; now: Date; alreadySent: number }): { level: 50 | 70; message: string } | null {
  const pct = (i.estimated / HOBBY_EDGE_REQUESTS) * 100;
  const level = pct >= 70 ? 70 : pct >= 50 ? 50 : null;
  if (!level || level <= i.alreadySent) return null;
  const day = i.now.getUTCDate();
  const daysInMonth = new Date(Date.UTC(i.now.getUTCFullYear(), i.now.getUTCMonth() + 1, 0)).getUTCDate();
  const hitDay = Math.ceil(HOBBY_EDGE_REQUESTS / (i.estimated / day));
  const when = hitDay <= daysInMonth
    ? new Date(Date.UTC(i.now.getUTCFullYear(), i.now.getUTCMonth(), hitDay)).toLocaleDateString("en-GB", { day: "numeric", month: "long", timeZone: "UTC" })
    : null;
  return {
    level,
    message: `Edge requests are an estimated ${Math.round(pct)}% of Hobby's 1,000,000 this month. ${when ? `At this rate they reach 100% on ${when}.` : "At this rate they stay under 100% this month."} Check the Vercel usage page and decide whether to upgrade to Pro ($20, about £16 a month).`,
  };
}
```

```ts
import { authorizeCron } from "@/lib/cronAuth";
import { DAY_MS, dayKey } from "@/lib/day";
import { digLaunchDate } from "@/lib/dig/clock";
import { estimateEdgeRequests, evaluateHealth, usageAlert } from "@/lib/dig/health";
import { funnelDays, healthReads, housekeep, markUsageAlert, writeHeartbeat, writesRedis } from "@/lib/dig/server";
import { sendDigAlert } from "@/lib/email";
import { getTrafficDays } from "@/lib/trafficStats";

export const dynamic = "force-dynamic";

/** Daily at 07:00 UTC (vercel.json): checks the dig's buffer and freshness, estimates
 * the month's edge requests, sets yesterday's counter expiries, writes the heartbeat the
 * pipeline checks, and emails Sam once if anything needs a look. Production only. */
export async function GET(req: NextRequest) {
  const { denied } = authorizeCron(req);
  if (denied) return denied;
  if (!writesRedis()) return NextResponse.json({ skipped: "not production" });
  const now = new Date();
  const today = dayKey(now);
  const tomorrow = dayKey(new Date(now.getTime() + DAY_MS));
  const yesterday = dayKey(new Date(now.getTime() - DAY_MS));
  const month = today.slice(0, 7);
  try {
    const reads = await healthReads(today, tomorrow, month);
    if (!reads) return NextResponse.json({ error: "Redis not configured" }, { status: 500 });
    const problems = evaluateHealth({ today, manifest: reads.manifest, todayExists: reads.todayExists, tomorrowExists: reads.tomorrowExists, launch: digLaunchDate(), now });

    const dayOfMonth = now.getUTCDate();
    const monthDates = Array.from({ length: dayOfMonth }, (_, i) => `${month}-${String(i + 1).padStart(2, "0")}`);
    const [dig, site] = await Promise.all([funnelDays(monthDates), getTrafficDays(dayOfMonth, now)]);
    const sum = (days: Record<string, Record<string, number>>, prefix: string) =>
      Object.values(days).reduce((a, h) => a + Object.entries(h).reduce((b, [f, n]) => (f.startsWith(prefix) ? b + n : b), 0), 0);
    const alert = usageAlert({ estimated: estimateEdgeRequests(sum(dig, "land:"), sum(site, "visit:")), now, alreadySent: reads.usageSent });
    if (alert) problems.push(alert.message);

    await housekeep(yesterday);
    await writeHeartbeat(now);
    if (problems.length) {
      await sendDigAlert(problems);
      if (alert) await markUsageAlert(month, alert.level);
    }
    return NextResponse.json({ problems: problems.length });
  } catch (err) {
    console.error("dig-health failed", err instanceof Error ? err.name : "unknown");
    return NextResponse.json({ error: "failed" }, { status: 500 });
  }
}
```

```ts
import { DAY_MS, dayKey, dayStart } from "../day";

export type DigFunnelRow = { date: string; land: number; start: number; finish: number; share: number; story: number; signup: number; past: number };
export type DigFunnelSummary = { rows: DigFunnelRow[]; killLine: number | null };

const sum = (h: Record<string, number>, prefix: string) => Object.entries(h).reduce((a, [f, n]) => (f.startsWith(prefix) ? a + n : a), 0);

/** Daily players = start (architecture §9). The kill check is the median daily start over
 * days 22–28 after launch: below 20 means stop. Null until all seven days have passed. */
export function summarizeDigFunnel(days: Record<string, Record<string, number>>, launch: string | null): DigFunnelSummary {
  const rows = Object.entries(days)
    .map(([date, h]) => ({
      date, land: sum(h, "land:"), start: h.start ?? 0, finish: h.finish ?? 0, share: sum(h, "share:"),
      story: h.story ?? 0, signup: h.signup ?? 0, past: h["past:start"] ?? 0,
    }))
    .sort((a, b) => b.date.localeCompare(a.date));
  let killLine: number | null = null;
  if (launch) {
    const window = Array.from({ length: 7 }, (_, i) => dayKey(new Date(dayStart(launch).getTime() + (21 + i) * DAY_MS)));
    if (window.every((d) => d in days)) {
      const starts = window.map((d) => days[d].start ?? 0).sort((a, b) => a - b);
      killLine = starts[3];
    }
  }
  return { rows, killLine };
}
```
